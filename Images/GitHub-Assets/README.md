## نکات فنی

- فایل‌های SVG برداری هستند و با تغییر اندازه، کیفیت آن‌ها مانند تصاویر Raster افت نمی‌کند.
- برای نمایش مستقیم در GitHub از مسیر نسبی فایل در مخزن استفاده کنید.
- برای استفاده در وب‌سایت یا نرم‌افزار، سازگاری SVG و قابلیت‌های انیمیشن را در مرورگر یا محیط مقصد بررسی کنید.
- اگر SVG در یک محیط خاص نمایش داده نشد، نسخه PNG خروجی‌گرفته‌شده از فایل اصلی می‌تواند جایگزین باشد.
- فایل‌ها را با حفظ نام و ساختار پوشه نگهداری کنید تا لینک‌های READMEهای دیگر مخزن خراب نشوند.

## Technical Notes

- SVG files are vector-based and can be resized without the raster-scaling quality loss associated with bitmap images.
- Use repository-relative paths to render the files directly on GitHub.
- When embedding the assets in a website or application, verify SVG and animation support in the target browser or runtime.
- If a particular environment cannot render an SVG, export a PNG version as a fallback.
- Preserve file names and directory structure to avoid breaking links in other repository documentation.
