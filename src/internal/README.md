# Internal Library Components

This directory contains private helpers used by the HAL implementation. These are not intended as stable application-facing APIs.

## Files

| File | Description |
|---|---|
| `mod.rs` | Internal module declarations |
| `drop.rs` | Resource cleanup and Drop-related implementation |
