## فایل‌ها

# USB High-Speed Module

This directory contains the USB High-Speed implementation, including endpoint control, data transfers and controller-specific registers.

## Files

| File | Description |
|---|---|
| `mod.rs` | Main USBHS controller implementation |
| `control.rs` | Control transfer handling |
| `endpoint.rs` | Endpoint and data-transfer management |
| `regs.rs` | Controller register and bit definitions |
