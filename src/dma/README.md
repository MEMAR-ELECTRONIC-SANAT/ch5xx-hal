# DMA Submodules

This directory separates DMA helper components from the main driver logic.

## Files

| File | Description |
|---|---|
| `address.rs` | DMA transfer address definitions and calculations |
| `buffer.rs` | Buffer utilities and memory constraints for DMA operations |
