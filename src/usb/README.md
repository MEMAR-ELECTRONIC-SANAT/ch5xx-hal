# USB Full-Speed Module

This directory organizes the USB Full-Speed device implementation, including controller logic, buffers and USB events.

## Files

| File | Description |
|---|---|
| `mod.rs` | Main USB device implementation and endpoint management |
| `buffer.rs` | USB buffer structures and helpers |
| `events.rs` | USB event and state definitions |
