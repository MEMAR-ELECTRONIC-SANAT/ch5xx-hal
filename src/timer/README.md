# Timer Module

This directory contains timer APIs and helpers, including counters, input capture, simple PWM and shared configuration types. Feature availability can vary by device.

## Files

| File | Description |
|---|---|
| `counter.rs` | Timer counter and event-counting support |
| `input_capture.rs` | Input signal edge/timestamp capture |
| `low_level.rs` | Low-level timer resource access |
| `simple_pwm.rs` | Timer-based simple PWM support |
| `types.rs` | Shared timer types and configuration structures |
